# マイ・ニュースデスク

自分の興味のあるニュースだけを、要約つきで1ページにまとめた個人用ニュースサイトです。
各記事の「詳しく読む ↗」から元の記事に移動できます。

## 収録カテゴリ

| カテゴリ | 主な出典 |
|---|---|
| アクセンチュア | アクセンチュアのニュースリリース（PR TIMES、財経新聞、Accenture Newsroom） |
| 毎日新聞 社説 | 毎日新聞（mainichi.jp） |
| 情報法 | 個人情報保護法・AI法・プラットフォーム規制・サイバー関連法制などの報道や官公庁の発表 |
| サイバー | サイバー攻撃・情報漏えい・脆弱性のニュース |
| FX・株式 | みんかぶ FX/為替（主要通貨）、株探など株式市況 |

## 仕組み

- `index.html` … ページ本体。`news.json` を読み込んで表示し、1分ごとに更新を確認します。
- `news.json` … 記事データ（見出し・URL・出典・掲載日・要約）。
- 記事の収集と要約は Claude の定期タスクが1時間ごとに行い、`news.json` を更新してこのリポジトリに反映します。
- 保存期間は約3か月（90日）で、それより古い記事は自動で削除されます。

## 公開（GitHub Pages）

Settings → Pages → Build and deployment で
**Source: Deploy from a branch / Branch: `main` / フォルダ: `/ (root)`** を選んで保存すると、
`https://information000.github.io/my-news-desk/` で見られるようになります。

## 注意

要約は元記事をもとに独自に書き直したものです。記事の著作権は各配信元にあります。
社説の要約は見出しと公開情報から作成しているため、詳しい論旨は元記事で確認してください。
